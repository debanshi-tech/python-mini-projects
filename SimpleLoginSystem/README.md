# Simple Login System

## Description

A simple login system built using Python that checks whether the entered username and password match the correct login credentials.

## Features

- Takes username and password as input
- Checks the entered credentials
- Displays a successful login message for correct credentials
- Displays an error message for incorrect credentials

## Login Credentials

- Username: `admin`
- Password: `1234`

## Concepts Used

- Variables
- User input
- `input()`
- `int()`
- Strings
- `if-else`
- Logical operator (`and`)
- Comparison operators

## How to Run

1. Make sure Python is installed.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python login.py
```

## Example

### Successful Login

```text
Enter your username: admin
Enter your password: 1234
Login Successful!
```

### Invalid Login

```text
Enter your username: user
Enter your password: 5678
Invalid username or password
```

Through this project, I practiced working with strings and user input, comparing values, and using the logical `and` operator with conditional statements to create a simple authentication system.
