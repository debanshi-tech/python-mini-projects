# Student Grade Calculator

## Description

A simple Python program that takes a student's marks as input and determines the corresponding grade.

## Features

- Accepts marks from the user
- Checks whether the entered marks are valid
- Assigns grades based on the marks
- Handles invalid marks below 0 or above 100

## Grading System

| Marks | Grade |
|---|---|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

## Concepts Used

- Variables
- User input
- `float()`
- `if-elif-else`
- Comparison operators
- Logical operators (`or` and `and`)

## How to Run

1. Make sure Python is installed.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python grade_calculator.py
```

## Example

```text
Enter your marks: 85
A
```
