# Simple Calculator

## Description

A simple calculator built using Python that performs basic arithmetic operations based on the user's choice.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Displays an error for invalid operators

## Concepts Used

- Variables
- User input
- `float()`
- `if-elif-else`
- Comparison operators
- Arithmetic operators

## How to Run

1. Make sure Python is installed.
2. Open the terminal in the project folder.
3. Run the following command:

```bash
python calculator.py
```

## Example

```text
Enter first number: 10
Enter second number: 5
Choose an operation (+, -, *, /): *

Multiplication: 50.0
```
